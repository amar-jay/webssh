# Repository instructions

## README protection

NEVER OVERWRITE THE README.

- Treat every README file in this repository as user-owned content.
- Never change the root `README.md` unless the user explicitly requests that specific change.
- Subdirectory READMEs may receive targeted factual corrections when their contents no longer match the implementation. Preserve their structure, voice, and all unrelated content; do not rewrite them.
- Do not replace, truncate, delete, regenerate, or reformat README files.
- Preserve README files when running scaffolders, generators, installers, or setup commands. Back them up before running tools that might overwrite them, and restore their exact contents afterward.
- Put setup notes and implementation documentation in other files under `docs/` unless the user explicitly requests a README update.
